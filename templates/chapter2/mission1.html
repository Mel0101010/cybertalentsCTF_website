Votre premier défi sera d'utiliser le protocole TCP, et de renvoyer au serveur le contenu qu'il vous envoie, un simple écho.

📡 Informations du Serveur

IP : ?.?.?.?

Port : 9001

Protocole : TCP

💡 Exemple de Code Python

import socket

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9001))

# Recevoir les données
data = s.recv(1024)

# Renvoyer les mêmes données
s.send(data)

# Recevoir la réponse finale
response = s.recv(1024)
print(response.decode())

# Fermer la connexion
s.close()
Besoin d'un indice ?
