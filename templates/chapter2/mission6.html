Mission #6: Devinez le Nombre

STATUT: EN COURS

📋 Briefing de Mission

Dans cette mission, vous devez créer un programme qui joue à un jeu de devinettes avec le serveur. Le serveur choisit un nombre entre 1 et 100, et votre programme doit le deviner en utilisant le moins de tentatives possible.

À chaque tentative, le serveur vous indiquera si votre nombre est trop grand, trop petit, ou correct.

📡 Informations du Serveur

IP : ?.?.?.?

Port : 9006

Protocole : TCP

📝 Règles du Jeu

  1. Le serveur choisit un nombre entre 1 et 100
  2. Votre programme doit deviner ce nombre
  3. À chaque tentative, envoyez un nombre au serveur
  4. Le serveur répondra avec :
    • "HIGH" si votre nombre est trop grand
    • "LOW" si votre nombre est trop petit
    • "CORRECT" si vous avez trouvé le bon nombre
  5. Vous devez trouver le nombre en moins de 10 tentatives

💡 Exemple d'Interaction

Serveur : "Devinez le nombre entre 1 et 100"
Client  : "50"
Serveur : "HIGH"
Client  : "25"
Serveur : "LOW"
Client  : "37"
Serveur : "CORRECT! Voici le flag: GUESS_CORRECT"

🎯 Exemple de Stratégie

La recherche dichotomique (binary search) est la stratégie optimale :

  1. Commencez au milieu de l'intervalle (50)
  2. Si c'est trop grand, cherchez dans la première moitié (1-49)
  3. Si c'est trop petit, cherchez dans la seconde moitié (51-100)
  4. Répétez en prenant le milieu du nouvel intervalle

Cette stratégie garantit de trouver le nombre en maximum 7 tentatives.

Tentative Nombre proposé Réponse Nouvel intervalle
1 50 HIGH 1-49
2 25 LOW 26-49
3 37 CORRECT -

💻 Exemple de Code Python

import socket

def play_guessing_game(s):
    # Lire le message initial
    data = s.recv(1024).decode().strip()
    print("Serveur:", data)
    
    # Initialiser les bornes de l'intervalle
    low = 1
    high = 100
    
    while True:
        # Calculer le nombre à proposer (milieu de l'intervalle)
        guess = (low + high) // 2
        print("Proposition:", guess)
        
        # Envoyer la proposition
        s.send(str(guess).encode())
        
        # Recevoir la réponse
        response = s.recv(1024).decode().strip()
        print("Serveur:", response)
        
        if response == "CORRECT":
            return response
        elif response == "HIGH":
            high = guess - 1
        elif response == "LOW":
            low = guess + 1
        
        # Vérifier si l'intervalle est valide
        if low > high:
            return "ERREUR: Intervalle invalide"

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9006))

# Jouer au jeu
result = play_guessing_game(s)
print("Résultat final:", result)

# Fermer la connexion
s.close()
Besoin d'un indice ?

Indice : Pour optimiser votre recherche, utilisez la recherche dichotomique : 1. Gardez trace des bornes de l'intervalle (low et high) 2. Proposez toujours le nombre au milieu de l'intervalle 3. Ajustez les bornes en fonction de la réponse : - Si "HIGH", réduisez la borne supérieure - Si "LOW", augmentez la borne inférieure 4. Continuez jusqu'à obtenir "CORRECT" Cette stratégie divise l'intervalle par 2 à chaque tentative, garantissant de trouver le nombre en maximum 7 coups (log₂(100) ≈ 6.64).
