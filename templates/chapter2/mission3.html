💻 Exemple de Code Python

import socket

def decimal_to_binary(decimal_str):
    # Convertir la chaîne en nombre entier
    decimal = int(decimal_str)
    # Convertir en binaire et enlever le préfixe '0b'
    binary = bin(decimal)[2:]
    return binary

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9003))

# Recevoir le nombre décimal
data = s.recv(1024).decode().strip()

# Convertir et envoyer le nombre binaire
binary_result = decimal_to_binary(data)
s.send(binary_result.encode())

# Recevoir la réponse finale
response = s.recv(1024)
print(response.decode())

# Fermer la connexion
s.close()
Besoin d'un indice ?

Indice : Pour convertir un nombre décimal en binaire, vous pouvez : 1. Utiliser la fonction bin() de Python qui convertit directement en binaire 2. Implémenter l'algorithme de division par 2 : - Diviser le nombre par 2 - Garder le reste (0 ou 1) - Répéter avec le quotient jusqu'à obtenir 0 - Lire les restes de bas en haut N'oubliez pas d'enlever le préfixe '0b' de la représentation binaire.
