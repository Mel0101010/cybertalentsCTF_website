Mission #5: La Notation Polonaise Inverse

STATUT: EN COURS

📋 Briefing de Mission

Dans cette mission, vous devez créer un programme qui évalue des expressions mathématiques écrites en notation polonaise inverse (RPN).

La notation polonaise inverse est une méthode d'écriture des expressions mathématiques où les opérateurs suivent leurs opérandes. Par exemple, "3 4 +" signifie "3 + 4".

📡 Informations du Serveur

IP : ?.?.?.?

Port : 9005

Protocole : TCP

💡 Exemple d'Interaction

Serveur : "3 4 +"
Client  : "7"
Serveur : "Correct! Voici le flag: RPN_SOLVED"

Serveur : "5 3 4 * +"
Client  : "17"
Serveur : "Correct! Voici le flag: RPN_SOLVED"

📝 Comment fonctionne la RPN ?

Pour évaluer une expression RPN :

  1. Lire l'expression de gauche à droite
  2. Pour chaque nombre rencontré, l'empiler
  3. Pour chaque opérateur rencontré :
    • Dépiler les deux derniers nombres
    • Effectuer l'opération
    • Empiler le résultat
  4. Le résultat final est le seul nombre restant dans la pile

Exemple avec "5 3 4 * +" :

  1. Empiler 5 : [5]
  2. Empiler 3 : [5, 3]
  3. Empiler 4 : [5, 3, 4]
  4. Rencontrer * : 3 * 4 = 12, empiler : [5, 12]
  5. Rencontrer + : 5 + 12 = 17, empiler : [17]
  6. Résultat final : 17
Expression RPN Expression Infixe Résultat
3 4 + 3 + 4 7
5 3 4 * + 5 + (3 * 4) 17
2 3 4 + * 2 * (3 + 4) 14
10 5 - 3 * (10 - 5) * 3 15
15 7 1 1 + - / 3 * 2 1 1 + + - 15 / (7 - (1 + 1)) * 3 - (2 + (1 + 1)) 5

💻 Exemple de Code Python

import socket

def evaluate_rpn(expression):
    stack = []
    tokens = expression.split()
    
    for token in tokens:
        if token.isdigit() or (token[0] == '-' and token[1:].isdigit()):
            # C'est un nombre, on l'empile
            stack.append(int(token))
        else:
            # C'est un opérateur, on dépile les deux derniers nombres
            b = stack.pop()
            a = stack.pop()
            
            # On effectue l'opération
            if token == '+':
                stack.append(a + b)
            elif token == '-':
                stack.append(a - b)
            elif token == '*':
                stack.append(a * b)
            elif token == '/':
                stack.append(a // b)  # Division entière
            
    return stack[0]

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9005))

# Recevoir l'expression RPN
data = s.recv(1024).decode().strip()

# Évaluer l'expression et envoyer le résultat
result = str(evaluate_rpn(data))
s.send(result.encode())

# Recevoir la réponse finale
response = s.recv(1024)
print(response.decode())

# Fermer la connexion
s.close()
