Mission #4: Comptez les mots, pas les caractères

STATUT: EN COURS

📋 Briefing de Mission

Dans cette mission, vous devez créer un programme qui compte le nombre de mots dans un texte donné. Un mot est défini comme une séquence de caractères alphanumériques séparée par des espaces ou des signes de ponctuation.

Votre programme devra gérer correctement les espaces multiples, les signes de ponctuation, et les retours à la ligne.

📡 Informations du Serveur

IP : ?.?.?.?

Port : 9004

Protocole : TCP

💡 Exemple d'Interaction

Serveur : "Hello, world! This is a test."
Client  : "6"
Serveur : "Correct! Voici le flag: WORD_COUNT_DONE"

Serveur : "Multiple    spaces    and\nnewlines\nshould\nbe\nhandled"
Client  : "7"
Serveur : "Correct! Voici le flag: WORD_COUNT_DONE"

📝 Exemples de Textes

Exemple 1:
"Hello, world!"
Nombre de mots : 2

Exemple 2:
"Python is a programming language. It's easy to learn!"
Nombre de mots : 8

Texte Nombre de mots Explication
"Hello" 1 Un seul mot
"Hello world" 2 Deux mots séparés par un espace
"Hello, world!" 2 La ponctuation ne compte pas comme mot
"Hello world" 2 Les espaces multiples sont ignorés
"Hello\nworld" 2 Les retours à la ligne sont traités comme des espaces

💻 Exemple de Code Python

import socket
import re

def count_words(text):
    # Supprimer la ponctuation et convertir en minuscules
    text = re.sub(r'[^\w\s]', ' ', text)
    # Diviser le texte en mots et filtrer les chaînes vides
    words = [word for word in text.split() if word]
    return len(words)

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9004))

# Recevoir le texte
data = s.recv(1024).decode().strip()

# Compter les mots et envoyer le résultat
word_count = str(count_words(data))
s.send(word_count.encode())

# Recevoir la réponse finale
response = s.recv(1024)
print(response.decode())

# Fermer la connexion
s.close()

Compter la longueur de la liste résultante N'oubliez pas de gérer les cas particuliers comme : - Les espaces multiples - Les signes de ponctuation - Les retours à la ligne - Les apostrophes dans les mots
