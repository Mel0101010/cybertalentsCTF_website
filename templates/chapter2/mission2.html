Mission #2: 1+1=2

STATUT: EN COURS

📋 Briefing de Mission

Vous avez réussi à faire le plus compliqué, maintenant, nous pouvons commencer à augmenter la difficulté.

Vous devez renvoyer au serveur la somme des nombres qu'il vous envoie.

📡 Informations du Serveur

IP : ?.?.?.?

Port : 9002

Protocole : TCP

💡 Exemple d'Interaction

Serveur : "5 3"
Client  : "8"
Serveur : "Correct! Voici le flag: SUM_CORRECT"

Serveur : "10 20 30"
Client  : "60"
Serveur : "Correct! Voici le flag: SUM_CORRECT"

💻 Exemple de Code Python

import socket

def calculate_sum(numbers_str):
    # Convertir la chaîne en liste de nombres et calculer la somme
    numbers = [int(x) for x in numbers_str.split()]
    return sum(numbers)

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9002))

# Recevoir les nombres
data = s.recv(1024).decode().strip()

# Calculer et envoyer la somme
sum_result = str(calculate_sum(data))
s.send(sum_result.encode())

# Recevoir la réponse finale
response = s.recv(1024)
print(response.decode())

# Fermer la connexion
s.close()
Besoin d'un indice ?

Indice : Le serveur envoie une chaîne de nombres séparés par des espaces. Vous devez parser cette chaîne, convertir les nombres en entiers, calculer leur somme, et renvoyer le résultat sous forme de chaîne. N'oubliez pas de gérer les espaces et la conversion des types.
