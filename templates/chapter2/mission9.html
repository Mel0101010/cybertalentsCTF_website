📝 Qu'est-ce que la compression RLE ?

Run-Length Encoding (RLE) est une méthode de compression de données simple qui remplace les séquences répétées par une paire (compte, valeur).

Par exemple :

  • "AAAA" devient "4A"
  • "BBBBBB" devient "6B"
  • "AABBBCC" devient "2A3B2C"

Cette méthode est efficace pour les données contenant beaucoup de répétitions.

💻 Exemple de Code Python

import socket

def compress_rle(text):
    if not text:
        return ""
    
    result = []
    count = 1
    current = text[0]
    
    for char in text[1:]:
        if char == current:
            count += 1
        else:
            result.append(f"{count}{current}")
            count = 1
            current = char
    
    result.append(f"{count}{current}")
    return "".join(result)

def decompress_rle(text):
    result = []
    i = 0
    while i < len(text):
        # Extraire le nombre
        count = ""
        while i < len(text) and text[i].isdigit():
            count += text[i]
            i += 1
        count = int(count)
        
        # Extraire le caractère
        if i < len(text):
            char = text[i]
            result.append(char * count)
            i += 1
    
    return "".join(result)

def compress_binary(data):
    if not data:
        return ""
    
    result = []
    count = 1
    current = data[0]
    
    for bit in data[1:]:
        if bit == current:
            count += 1
        else:
            result.append(f"{count}:{current}")
            count = 1
            current = bit
    
    result.append(f"{count}:{current}")
    return " ".join(result)

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9009))

while True:
    # Recevoir la commande et les données
    data = s.recv(1024).decode().strip()
    if not data:
        break
    
    # Analyser la commande
    if data.startswith("COMPRESS:"):
        text = data.split(":", 1)[1].strip()
        response = compress_rle(text)
    elif data.startswith("DECOMPRESS:"):
        text = data.split(":", 1)[1].strip()
        response = decompress_rle(text)
    elif data.startswith("COMPRESS_BINARY:"):
        binary = data.split(":", 1)[1].strip()
        response = compress_binary(binary)
    else:
        response = "ERROR: Commande non reconnue"
    
    # Envoyer la réponse
    s.send(response.encode())
    
    # Recevoir la confirmation
    confirmation = s.recv(1024).decode()
    print(confirmation)
    
    if "flag" in confirmation.lower():
        break

# Fermer la connexion
s.close()
Besoin d'un indice ?

Indice : Pour implémenter la compression RLE, vous pouvez : 1. Pour la compression : - Parcourir le texte caractère par caractère - Compter les répétitions consécutives - Créer une paire (compte, caractère) pour chaque séquence - Joindre les paires pour former le résultat 2. Pour la décompression : - Extraire les paires (compte, caractère) - Répéter chaque caractère selon son compte - Joindre les résultats 3. Pour les données binaires : - Utiliser le même principe mais avec des bits - Formater la sortie avec des séparateurs - Gérer les cas spéciaux (0, 1) N'oubliez pas de : - Gérer les cas limites (texte vide, caractères uniques) - Vérifier la validité des données - Optimiser pour les grands ensembles de données
