📝 Qu'est-ce que le JSON ?

JSON (JavaScript Object Notation) est un format de données léger utilisé pour l'échange de données. Il est facile à lire et à écrire pour les humains, et facile à analyser et à générer pour les machines.

Les types de données JSON incluent :

  • Objets : collections de paires clé-valeur
  • Tableaux : listes ordonnées de valeurs
  • Chaînes : texte entre guillemets
  • Nombres : entiers ou décimaux
  • Booléens : true ou false
  • null : valeur nulle

🔤 Syntaxe JSON

{
    "string": "texte",
    "number": 42,
    "float": 3.14,
    "boolean": true,
    "null": null,
    "array": [1, 2, 3],
    "object": {
        "key": "value"
    }
}

💻 Exemple de Code Python

import socket
import json

def process_json(data, task):
    # Convertir la chaîne JSON en dictionnaire Python
    json_data = json.loads(data)
    
    # Extraire les données et la tâche
    items = json_data.get('data', [])
    filter_condition = json_data.get('filter', '')
    
    # Appliquer le filtre
    if '>' in filter_condition:
        field, value = filter_condition.split('>')
        field = field.strip()
        value = int(value.strip())
        result = [item for item in items if item[field] > value]
    elif 'active' in filter_condition:
        result = [item for item in items if item.get('active', False)]
    else:
        result = items
    
    # Créer la réponse
    response = {'result': result}
    return json.dumps(response)

# Créer un socket TCP
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
s.connect(('IP_DU_SERVEUR', 9008))

# Recevoir les données JSON
data = s.recv(4096).decode().strip()

# Traiter les données
response = process_json(data, None)

# Envoyer la réponse
s.send(response.encode())

# Recevoir la réponse finale
final_response = s.recv(1024)
print(final_response.decode())

# Fermer la connexion
s.close()
